# 首页

在这里，生存只是开场，真正的核心是——以社会模拟为底色的古风世界。

我们以古代为背景展开社会模拟类玩法，以古风国风传统为主要元素，鼓励玩家扮演各式各样的职业角色：清晨下田采茶的茶农、在花圃间忙碌的花农、往来于城镇之间的跑商、在酒坊里细心酿造的酿酒师……每一位玩家，都是这个世界运转的一颗齿轮。

在这里，你可以：

- 通过 EchoMarket 全球市场 开设属于自己的 NPC 商店，把茶叶、花卉、酒水、特产一并上架，做全服闻名的大掌柜；
- 借助 PrismMarket 棱镜市场 参与动态经济，在限时商店与轮换货架间寻找暴富机遇，精打细算做最聪明的商人；
- 使用 Transportation 坐骑系统 缔结契约坐骑，给你的茶马古道、花田跑商之路配上一匹真正“灵魂绑定”的战马；
- 通过 Milestone 里程碑成就 记录每一次耕作、建造、探索与交易，把“生活”一点一点写进自己的成长史。

我们希望构建的是一个秩序与温度并存的社区：有规则、有底线，也有长期相处的邻里与伙伴。服务器内设有详尽的《客官守则》与违规指数系统，对一切作弊、破坏他人体验的行为采取严厉处罚——严禁一切作弊，0 容忍熊孩子 。恶意玩家将被快速处理并全服通报，只为还真正热爱建设与互动的玩家一片干净的天空。

如果你厌倦了快餐式刷子与无脑破坏，想尝试在方块世界里“认真过日子”、发展自己的小事业、结识同样讲规则、懂礼貌的同好，那就整理好行囊吧——来这里，挑一个你喜欢的职业，从一间小屋、一片田地、一笔小本生意开始，一起把这个古风世界，慢慢建设成我们共同的家园。

欢迎来到 PrismMarket 官方帮助维基。  
这套文档采用“从入门到进阶”的结构，覆盖安装、配置、运营、排障与维护全流程，适合作为服主与技术管理组的标准手册。

> ✅ 适用对象：服主、管理、配置维护者、整合包/玩法设计者  
> ✅ 适用版本：当前仓库主线实现（Paper/Folia + Java 21+）

---

## PrismMarket 能做什么

- 💫 图形化商店交易（分页、数量选择、点击买卖）
- 📈 动态定价（可按玩家/全服交易量驱动）
- 🎲 随机轮换商店（周期刷新、阻断窗口、防并发交易）
- 🧪 `custom:xxx` 基准物品体系（含 hash 校验）
- 🧩 CraftEngine 物品直接接入（`craftengine:namespace:id`）
- 🧾 交易日志查询与玩家行为可观察化
- 🌍 多语言文本 + PAPI 占位符兼容

# 📈 生产环境运维建议

## 发布前检查

- 依赖完整（Vault + 经济插件）
- `default-shop` 可打开
- 至少完成一次买卖测试
- 随机组 `start/time/mode` 语义正确
- custom 基准已录入关键商品

## 日常运维节奏（建议）

### 每日

- 抽查 1~2 个核心商店 GUI
- 观察随机组是否按计划刷新
- 查看异常报错与交易失败提示

### 每周

- 审查交易日志热点商品
- 调整限额与价格曲线
- 备份数据库

## 事故处理建议

### 价格异常

1. 临时切固定价
2. 关闭对应随机组或强制刷新
3. 回放日志确认影响范围

### custom 失效

1. `/pm debug memory custom` 检查加载
2. `/pm debug saveitem <itemId>` 重建基准
3. `/pm reload memory` 生效

### 随机组错乱

1. `/pm debug change <shopId> info` 看当前状态
2. 必要时 `force confirm` 修正

## 配置治理建议

- 将生产配置纳入版本管理
- 对高风险字段（价格函数、刷新周期）采用双人复核
- 保留“测试商店”用于演练配置变更

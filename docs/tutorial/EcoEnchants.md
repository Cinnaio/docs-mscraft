# EcoEnchants 附魔图鉴

**自定义附魔**从下文「普通」起按稀有度排列；**原版附魔**在文末 [原版附魔](#vanilla-enchants) 折叠表。

- **铁砧**：单件装备上附魔**合计最多 10 条**（原版 + 自定义一起算），满后不能再往上叠。
- **表格 ✅ / ❌**：会不会从附魔台、村民、战利品里随机出现；「❌」也可能通过别的途径拿到，以服内为准。
- **「类别」列**：限制同一件上某类附魔能叠几条，和「稀有度」不是一回事（稀有度档位里的「**特殊**」≠ 类别「**特异类**」）。
- **「随等级」**：同一附魔等级越高，该条里提到的数值、概率、持续时间等通常越强；**各级具体数字**见下文 [附魔每级数值](#per-level-stats)（仍以游戏内结算为准）。

| 类别 | 同一件装备 |
|:---:|:---:|
| 常规 | 不按类别限条数（仍受合计 ≤10） |
| 诅咒 | 最多 2 条 |
| 法术类 | 最多 1 条 |
| 特异类 | 最多 1 条 |

下表的**稀有度**（普通～超特殊）决定附魔在三条渠道里「抽到这一档」的相对机会；和上面「常规 / 诅咒 / 法术类…」那种**类别**不是同一套概念。

## 附魔每级数值 {#per-level-stats}

下面这张表是给**玩家**看的：告诉你**附魔书、铁砧、物品说明**里出现的那串数字，从 **I 级到最高级**一般会怎么变。

- **L** 表示附魔等级（**L = 1** 就是 **I 级**，**L = 2** 就是 **II 级**，以此类推）。
- 第三列里用顿号、逗号隔开，**从左到右依次是 I 级、II 级、III 级……** 直到这一附魔的常见最高级（不是「从 4% 变到 16%」这一种意思，而是「I 级对应 4%，II 级对应 8%……」）。
- **原版**里像保护、击退这类，说明上的数字还会和护甲、抗性、多件装备一起参与游戏内置公式，**实际挨打/打人手感**不一定和说明里的百分数一模一样，这里列的是**说明上会怎么写**。
- **自定义**附魔里，若某一格写了「说明」和「实际」两行，表示**界面上写的**和**后台真正用来结算的**不完全一致，以游戏里为准。

（数据来自本服务器 EcoEnchants 的配置；**20 tick ≈ 1 秒** 用于冷却换算。）

**读数小提示**：式子写成 **(A + B × L)%** 这种、**整个括号后面才是 %** 的，表示「伤害/经验/几率等提高百分之多少」，**不是**「先 +A 点固定伤害」。没写 **%** 的一串数字，一般是游戏里的**伤害刻度、格数、秒数、件数**等，**不等于**对方直接少几颗心（❤），以游戏内说明为准。

## 装备列在说什么 {#gear-types}

「剑」「镐」「护甲」等 = 该类型下**各材质**（原版有就列得进）。三叉戟、弓、弩等是**单一物品**没有材质分档。

**全物品**：不绑死某一类工具；能不能附，用铁砧 / 附魔台试最准。

附魔台还可对 **鞘翅、盾牌、打火石、剪刀、胡萝卜钓竿、玩家头颅** 附魔（表中不一定逐条写出）。

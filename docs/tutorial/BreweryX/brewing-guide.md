# BreweryX 酿酒大师指南

欢迎来到 **BreweryX** 的微醺世界！在这里，你将亲手化身为一名真正的酿酒大师，从田间地头的一粒小麦，到木桶中陈年的醇香美酒，全程参与，点滴酿造。无论是清爽的啤酒、温润的黄酒，还是烈性的伏特加，都等你来解锁。准备好你的炼药锅，我们开工！

## 核心概念

::: info 酿酒四步曲
在开酿之前，你需要了解酿酒的四个核心步骤：
1.  **蒸煮**：将原料（如小麦、浆果）放入炼药锅中煮沸，转化为“麦芽汁”或“果基酒”。
2.  **蒸馏**：通过酿造台多次提纯，获得更高酒精度的烈酒。
3.  **陈酿**：将酒装入酒桶，等待岁月赋予它色泽与风味。
4.  **封装**：将陈酿好的酒放入封装台进行锁封装，锁定品质。
:::

## 准备工作：建造酒桶

酒桶是陈酿的必需工具，你需要先亲手制作它。

1.  **收集材料**：根据你要酿造的酒，选择对应木材的木板（例如橡木、白桦木、云杉木等）和同种木材的木楼梯。
2.  **搭建酒桶**：将木板和木楼梯按照下图方式摆放：

   * *图中黄/黑色混凝土仅作为长度示意，并非酒桶的一部分。*
   * *大酒桶有27格储藏空间，小酒桶有9格储藏空间。*

3.  **激活酒桶**：建造完酒桶的主体结构后，在酒桶上放置**告示牌**，并在告示牌的第一行写上 `barrel`，即可成功创建一个可用的酒桶。

## 蒸煮原料

### 1. 准备原料
首先，你需要收集配方所需的材料。例如，一瓶基础啤酒可能需要：
- 16 个小麦
- 一个水源（无限水或一桶水）
- 一个炼药锅
- 一个火源（营火或灵魂营火）
- 几个玻璃瓶

### 2. 开始煮沸
1.  用 **水桶** 右键炼药锅，将它装满水。
2.  在炼药锅下方放置营火。
3.  将配方要求的原料拿在手上，依次右键放入炼药锅。
4.  炼药锅冒出**水花颗粒和气泡**时，表示正在蒸煮。
5.  使用 **时钟** 右键炼药锅查看当前已煮时间。
6.  煮够时间后，手持 **玻璃瓶** 右键炼药锅，获得基酒。

## 蒸馏提纯

如果你酿造的是需要蒸馏的酒（如白酒、伏特加），请继续以下步骤：

1.  右键点击 **酿造台** 打开界面。
2.  将基酒瓶放入酿造台的下方格子。
3.  在原料格（上方格子）放入 **萤石粉** 作为滤材（不需要烈焰粉）。
4.  蒸馏将自动开始，持续约 60 秒。
5.  如果配方需要多次蒸馏，酿造台会自动连续进行。

::: tip 小贴士
蒸馏次数不足会导致酒精度偏低；次数过多则可能使酒变味，品质下降。务必按照配方精准操作！
:::

## 陈酿时光

这一步是让酒脱胎换骨的关键。

1.  **确认酒桶材质**：确保酒桶材质与配方要求一致（如黄酒用竹板酒桶）。
2.  **存入酒瓶**：将酒存入桶中。
3.  **等待陈酿**：陈酿时间以 **Minecraft 年** 为单位（游戏内 20 分钟 = 1 年）。右键点击酒桶可查看状态。
4.  **取出成品**：达到最佳年份后，再次右键点击酒桶取出。

::: warning 注意
陈酿时间不足或过长都会影响最终品质。只有恰到好处的年份才能酿出“好品质”的酒。务必把握好时机，避免“陈年过度”。
:::

## 进行密封

拿着你酿好的酒，将它放入冲泡密封台，它将自动进行密封。

![密封台搭建图](https://github.com/user-attachments/assets/eb09a713-8f02-44ba-9650-8d1d6cccafbb)

密封后，酒的品质就不会再变化，非常适合处理需要运输或者售卖的酒品。

## 常见问题

::: details Q: 为什么我的酒品质总是差的？
检查一下：原料数量是否正确？煮的时间够不够？蒸馏次数是否准确？陈酿年份是否恰好？每一步都会影响最终品质。
:::

::: details Q: 酒桶里的酒能放多久？
理论上可以无限存放，但超过最佳年份后，品质会逐渐下降。建议记好时间及时取出。
:::

::: details Q: 陈酿酒时我需要一直在线吗？
不需要，陈酿是一个后台过程，不需要玩家一直在线也不需要酒桶所在区块一直加载。
:::

::: details Q: 我可以批量酿酒吗？
当然！你可以同时使用多个炼药锅、多个酒桶来批量生产。只要你有足够的原料和容器。
:::

在本目录下可以找到所有公开酒的配方攻略。如果你想了解某些私酿酒的配方，请咨询配方持有者。
:::

## 📌 通用提示

- **蒸煮**：将原料放入下方有营火的炼药锅中，用水桶装满水后依次右键放入原料，用时钟右键可查看剩余时间。
- **蒸馏**：将基酒放入酿造台，燃料格放入萤石粉，会自动进行指定次数的蒸馏。
- **陈酿**：将酒瓶存入对应木材的酒桶中，等待指定年份后取出。
- **密封**：将酒放入密封台中自动密封，密封后酒店品质不会变化。
- **木材对应表**：橡木（2）、白桦木（1）、竹子（11）等。建造酒桶时需使用对应木材的木板和木楼梯。
- **品质与恢复量**：最终酒的品质影响精力恢复量。严格按照配方操作可提升获得高品质酒的概率，从而获得更高的恢复加成。


如需了解更详细的步骤，请参阅服务器内的完整酿酒指南。

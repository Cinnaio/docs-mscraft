# 坐骑指南

> **核心摘要**：Transportation 提供“坐骑契约 + 兽栏管理 + 信物召唤/收回”。你可以随时召唤你的坐骑，并保留坐骑的速度、跳跃、装备等属性。

## 核心概念

:::: info 三个关键词
- **契约（Contract）**：你与生物建立绑定关系。绑定后它才算“属于你”，并受系统保护。
- **兽栏（Stable）**：坐骑的存储空间（类似数据库/亚空间）。不在身边的坐骑会在兽栏中休息。
- **信物（Token/Key）**：绑定到坐骑的物品媒介（如马铠、鞍、命名牌、木棍等），用于随时召唤/收回坐骑。
::::

## 缔结契约（绑定坐骑）

### 1) 驯服生物

先按原版方式驯服坐骑（例如马、驴、羊驼等）。

### 2) 绑定

将准星对准已驯服的生物，执行：

```
/tra bind
```

> 提示：绑定成功后，坐骑会进入你的兽栏，并记录速度、跳跃、生命值、装备、药水效果等属性。可以使用 */tra list* 来查看具体的已驯服生物的信息。

## 制作与使用信物（Key）

信物不是必须，但非常方便（尤其是频繁召唤/收回时）。

### 1) 制作信物

1. 手持一个你喜欢的物品（推荐：马铠/鞍/命名牌/木棍）。
2. 绑定为信物：

```
/tra keybind <坐骑代号>
```

示例：

- `/tra keybind HORSE#1`

::: tip 提示
所有的坐骑代号都可以使用TAB补全的哦~
:::

### 2) 使用信物

- **召唤**：手持信物，右键空气或地面
- **收回**：
  - 近距离：右键坐骑
  - 远距离：Shift + 右键空气或地面
- **骑乘**：空手（或手持非信物物品）右键坐骑

> 注意：不要手持信物去骑乘，会触发“收回”。

## 日常管理

### 查看兽栏

```
/tra list
```

你会看到坐骑状态（例如：出战中 / 休息中 / 重伤）。

### 无信物召唤/收回

- 召唤：`/tra out <代号>`
- 收回：`/tra in <代号>`

### 复活坐骑（重伤修复）

1. 用 `/tra list` 确认坐骑状态为 **[重伤]**
2. 执行修复：

```
/tra fix <代号>
```

示例：

```
/tra fix HORSE#1
```

## 社交与交易

### 转让坐骑

```
/tra transfer <代号> <玩家名>
```

转让后你的信物会失效，对方成为新的主人。

### 解除契约（删除坐骑）

```
/tra unbind <代号>
```

> 警告：该操作不可逆，坐骑将不再属于你。

## 安全与保护

- **防盗**：默认只有你可以骑乘你的坐骑（除非转让）。
- **防篡改**：其他玩家无法随意改动你的坐骑信息。
- **属性保留**：召唤/收回/转让都会保留速度、跳跃、装备、驯服状态与药水效果等。

## 常见问题（FAQ）

::::: details Q: 我的信物丢了怎么办？
A: 信物只是媒介，坐骑仍安全保存在兽栏中。你可以拿一个新的物品，重新执行 `/tra keybind <代号>` 绑定即可。
:::::

::::: details Q: 为什么提示“兽栏已满”？
A: 每位玩家可拥有的坐骑数量有限（由服务器设置）。你需要用 `/tra unbind <代号>` 释放不需要的坐骑。
:::::

::::: details Q: 我可以用命名牌改名吗？
A: 可以，作为主人你可以改名；其他玩家无法修改你的坐骑名字。
:::::

::::: details Q: 跨世界可以召唤吗？
A: 可以。兽栏跨世界生效，你可以在一个世界收回坐骑，在另一个世界召唤出来。
:::::

## 指令速查

| 咒语 (Command) | 参数 | 说明 |
| :--- | :--- | :--- |
| `/tra bind` | 无 | 将准星对准的生物缔结为坐骑 |
| `/tra keybind` | `[model#index]` | 将手中物品制作为信物 |
| `/tra list` | 无 | 查看所有坐骑及其状态 |
| `/tra out` | `<model#index>` | 从兽栏召唤坐骑 |
| `/tra in` | `<model#index>` | 将坐骑收回兽栏 |
| `/tra fix` | `<model#index>` | 复活已死亡的坐骑 |
| `/tra transfer` | `<model#index> <player>` | 将坐骑转让给他人 |
| `/tra unbind` | `<model#index>` | 解除契约（删除坐骑） |
| `/tra unkeybind` | 无 | 清除手中物品的信物属性 |

> 提示: `model#index` 里面的 “index” 表示的是你拥有该类型下的第几个，“model” 代表的是生物的类型。

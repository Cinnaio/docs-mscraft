# 💰 PrismMarket 棱镜市场指南

欢迎来到 **PrismMarket** 的世界！这是一个现代化的、动态的服务器经济系统。在这里，市场不再是一成不变的死水，而是随着时间流动、充满机遇与挑战的宝库。

---

## 🌟 核心概念 (Core Concepts)

在开始交易之前，请熟悉以下三个概念，它们将帮助你成为精明的商人：

1.  **动态商店 (Dynamic Shop)**: 市场中的商品并非永远固定。某些稀有物资可能会限时供应，或者价格随库存波动。
2.  **随机轮换 (Random Rotation)**: 特殊商店的货物会按照周期（如每天、每周）进行刷新。错过了今天的珍宝，可能要等很久才会再次出现！
3.  **限额 (Limits)**: 为了保证公平，部分商品设有“个人限购/售”或“全服限购/售”。对于全服限量的商品，手快有，手慢无！

## 🛒 第一章：开启市场 (Access)

### 1. 打开主菜单
在任何允许的地方，输入以下指令即可打开市场主界面：
```
/pm
```
*或者使用全称 `/prismmarket`*

### 2. 访问特定商店
如果你知道某个分店的代号（例如 `vip` 或 `materials`），可以直接跳转：
```
/pm <商店代号>
```
*例如：`/pm weekly` 直接打开周常随机商店。*

---

## 💰 第二章：交易指南 (Trading)

### 1. 购买与出售
在图形界面（GUI）中，操作非常直观：
*   **左键点击** 物品：通常进行 **购买** 操作。
*   **右键点击** 物品：通常进行 **出售** 操作。
*   *具体操作请留意物品的 Lore（描述）提示，不同服务器可能配置不同。*

### 2. 货币支持
PrismMarket 接入了服务器的经济系统（Vault）。
*   确保你的钱包里有足够的金币！
*   交易成功后，你会收到类似于 `<color:#6BFF95>购买了 钻石 x 1 花费 100` 的提示。

---

## 🔄 第三章：随机商店与刷新 (Refresh)

这是 PrismMarket 最激动人心的部分。

### 1. 刷新机制
某些商店（如“黑市”或“周常商店”）的货物列表不是固定的。
*   **每日刷新**: 每天固定时间（如 00:00）更换一批货物。
*   **每周刷新**: 每周固定时间（如周一）进货。
*   **单次刷新**: 某些特殊活动商店，只在特定时间开启一次。

### 2. 把握时机
*   当你在商品描述中看到 **"剩余时间"** 或 **"下次刷新"** 字样时，请注意！
*   一旦刷新，当前的商品列表将被重置，未买到的稀有物品可能会消失。

---

## 🚫 第四章：限制系统 (Limits)

为了防止市场被垄断，管理员可能会设置限制：

### 1. 个人限制 (Player Limit)
*   每个玩家对某件商品的交易数量有上限。
*   例如：“每日限购 10 个”。达到上限后，你今日将无法继续购买该商品。

### 2. 全服限制 (Server Limit)
*   全服务器所有玩家共享的交易池。
*   例如：“全服库存 500 个”。这是一种竞争机制，当全服玩家买光这 500 个后，该商品将售罄（Out of Stock），直到下次补货。

## ❓ 常见问题 (FAQ)

**Q: 为什么我点击物品没有反应？**
A: 可能是以下原因：
1.  你的背包满了（购买时）。
2.  你的钱不够了。
3.  该物品禁止购买/出售。
4.  达到了个人或全服的交易限制。

**Q: 我如何查看我还能买多少？**
A: 将鼠标悬停在商品图标上，描述中通常会显示当前的统计数据，例如 `个人限购: 5/10`。

**Q: 随机商店的物品对每个人都是一样的吗？**
A: 是的。随机商店的刷新是全服统一的，所有玩家看到的商品列表相同。这意味着如果那是全服限量的稀有品，你需要和别人抢购！

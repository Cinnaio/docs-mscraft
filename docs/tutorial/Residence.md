# 🏰 Residence 领地系统基础指南

欢迎来到 **Residence** 的世界！这是一个强大的领地保护插件，让你能够圈地建房、设置权限、与朋友共享空间。告别熊孩子破坏，在这里，你可以像真正的领主一样管理自己的土地。

---

## 🌟 核心概念 (Core Concepts)

在开始圈地之前，请熟悉以下三个概念：

1.  **领地 (Residence)**: 你通过木锄圈定的区域，可以是方形或任意形状。领地内的方块破坏、放置、交互等行为都可以被精细控制。
2.  **权限 (Permissions)**: 控制玩家在领地内能否做某事（如破坏、打开箱子）。可以单独为某个玩家或所有访客设置。
3.  **子领地 (Subzone)**: 在领地内部再划分的小区域，拥有独立的权限设置。适合多人团队各自分配房间。

---

## 🏗️ 第一章：创建领地 (Creating Residence)

### 1. 准备工作
*   你需要一把 **木锄**（可用 `/res tool` 直接获取）。
*   **💰 资金准备**：本服务器中，创建领地或扩展区域需要支付费用，价格为 **15.625 金币/每方块**。最终花费 = 领地总方块数 × 15.625。
*   **📏 间距规则**：不同领主的领地之间必须保持至少 **32 格** 的距离，请确保你选定的位置不会与其他玩家的领地冲突。

### 2. 圈地
使用木锄左键和右键选择两个对角点，框出你想要的范围：
1.  **左键** 第一个点（显示为绿色粒子）。
2.  **右键** 第二个点（显示为红色粒子）。
3.  输入指令创建领地：
    ```
    /res create [领地名称]
    ```
    *例如：`/res create myhome`*

> **✅ 成功后**: 你选择的区域就会被保护起来，只有你和被你允许的玩家可以建造。系统会从你的账户扣除相应金币，并自动赋予领地 **7天租期**（租期结束后需续租）。

### 3. 查看领地信息
*   **查看当前领地**: 站在领地内输入 `/res info`。
*   **查看所有领地**: 输入 `/res list`。

---

## 🔑 第二章：权限管理 (Permissions)

领地内默认只有主人可以建造。你可以通过以下指令为其他玩家开放权限。

### 1. 添加/移除领地成员
*   **添加允许建造的玩家**: `/res padd [玩家名]`（给玩家添加build权限）。
*   **移除玩家权限**: `/res pdel [玩家名]`。

### 2. 设置具体权限
Residence 的权限系统非常细致，格式为 `/res set [权限名] [true/false/remove]`。常用权限：
*   **build**: 建造/破坏方块。
*   **use**: 使用工作台、铁砧、门等。
*   **container**: 打开箱子、熔炉等容器。
*   **tp**: 允许玩家传送到领地。（*注：本服务器已禁用Residence传送功能，此权限无效。*）
*   **pvp**: 允许领地内PVP。

*例如：`/res set build true` 允许所有访客建造（通常不安全，建议单独给信任玩家权限）。*

> **💡 小贴士**: 对某个玩家单独设置权限使用 `/res pset [玩家名] [权限名] [true/false]`，例如 `/res pset Steve build true`。

## 📦 第三章：子领地 (Subzones)

如果你想在领地内划分出私人房间或公共区域，子领地是完美方案。

1.  站在父领地内，同样用木锄选择区域。
2.  输入指令创建子领地：
    ```
    /res subzone [子领地名称]
    ```
    *例如：`/res subzone bedroom`*
3.  子领地拥有独立的权限设置，可以覆盖父领地的权限。你可以用 `/res set` 在子领地内单独配置。

---

## 🧭 第四章：传送与删除 (Teleport & Removal)

> ⚠️ **重要提示：本服务器已禁用Residence插件的所有传送功能**，包括使用 `/res go` 指令传送到领地、通过权限让其他玩家传送等。如需返回领地，请自行步行或使用其他交通方式。

### 1. 传送功能
*   `/res go [领地名称]` **在本服务器中不可用**。

### 2. 删除领地
如果不再需要某块领地，可以删除它（**此操作不可逆，请三思**）：
1.  站在领地内输入 `/res remove`。
2.  系统会提示你输入 `/res confirm` 确认删除。
3.  **💰 出售返还**：删除领地后，系统会根据每方块 **5.625 金币** 的价格返还部分资金。

---

## 💰 第五章：经济与租期 (Economy & Renew)

本服务器已开启领地租期系统，所有领地创建时自动获得 **7天租期**。到期后若不续租，领地将被自动删除（物品会掉落）。

### 1. 领地费用一览
| 项目 | 价格（每方块） |
| :--- | :--- |
| 新建/扩展领地 | **15.625 金币** |
| 删除领地返还 | **5.625 金币** |
| 续租（7天） | **2.856 金币** |

### 2. 续租指令
在领地即将到期时，你可以使用以下指令续租：
```
/res renew [领地名称]
```
执行一次该指令，将为你的领地 **续租7天**，并从账户扣除相应金币（总费用 = 领地总方块数 × 2.856）。

> **📌 提示**：你可以随时使用 `/res info` 查看领地的剩余租期。

## ❓ 常见问题 (FAQ)

**Q: 如何扩大或缩小已有的领地？**
A: 可以使用 `/res expand [格数]` 向当前面朝方向扩大，或用 `/res contract [格数]` 缩小。扩展时会按新增方块数扣除费用。

**Q: 不同领主的领地之间需要保持多少距离？**
A: 服务器规定，不同领主的领地之间必须至少间隔 **32 格**。请在创建前使用 `/res select` 预览范围，避免冲突。

**Q: 如果我删除了领地，能拿回多少金币？**
A: 删除领地时，系统会按每方块 **5.625 金币** 的比例返还部分资金（前提是服务器主配置启用了返还功能）。

**Q: 领地如何续租？**
A: 使用 `/res renew [领地名称]` 即可续租7天。费用为每方块 **2.856 金币**。

**Q: 我可以传送到自己的领地吗？**
A: **不可以**。本服务器已禁止Residence插件的所有传送功能，请通过步行或其他交通方式到达领地。

**Q: 我可以转让领地主权给其他玩家吗？**
A: 可以，用 `/res give [领地名称] [玩家名]` 即可转让领地（需要你确认）。

**Q: 如何设置公共区域（所有人都可以建造）？**
A: 在领地内执行 `/res set build true` 会让所有玩家都能建造。如果要限制特定玩家，建议用 `/res pset` 单独设置。

**Q: 领地权限好像乱了，怎么重置？**
A: 可以使用 `/res default` 恢复领地的默认权限设置。

**Q: 如何查看某个玩家在我的领地里的权限？**
A: 输入 `/res pcheck [玩家名]` 即可查看该玩家在当前领地的所有权限。

| 指令 (Command) | 参数 | 说明 |
| :--- | :--- | :--- |
| `/res create` | `<名称>` | 创建领地（需先用木锄选点） |
| `/res remove` | `<名称>` | 删除指定领地（需确认） |
| `/res info` | 无 | 查看当前所在领地的信息 |
| `/res list` | 无 | 列出你拥有的所有领地 |
| `/res padd` | `<玩家名>` | 给玩家添加建造权限（简写版） |
| `/res pdel` | `<玩家名>` | 移除玩家的所有权限 |
| `/res pset` | `<玩家名> <权限> [true/false]` | 为特定玩家设置具体权限 |
| `/res set` | `<权限> [true/false/remove]` | 设置领地的默认权限（全局） |
| `/res expand` | `<格数>` | 向面朝方向扩大领地 |
| `/res contract` | `<格数>` | 向面朝方向缩小领地 |
| `/res subzone` | `<名称>` | 创建子领地 |
| `/res tool` | 无 | 直接获取选区木锄 |
| `/res give` | `<领地> <玩家>` | 将领地转让给其他玩家 |
| `/res pcheck` | `<玩家名>` | 查看玩家在当前领地的权限 |
| `/res renew` | `<领地>` | 续租领地（7天） |
| `/res confirm` | 无 | 确认危险操作（如删除领地） |

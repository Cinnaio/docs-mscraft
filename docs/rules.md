# msc群隙服务器客官守则

## 1. 总则 📜
1.1 严禁玩家进行任何违反中华人民共和国法律的行为，服务器将保存一切证据，违者后果自负。  
1.2 服务器核心理念：阐明本服为“玩家驱动的分流型经济社会模拟器”，核心玩法基于手动生产、地理物流、市场交易与契约精神。  
1.3 守则目的：为维护公平、可持续的游戏环境，保护玩家时间投入与资产安全，特制定本守则。所有玩家均视为已阅读并同意遵守。  
1.4 规则适用范围：适用于游戏内、官方社群、交易平台等一切与服务器相关的行为。  
1.5 规则漏洞的处理：如果出现“法未禁止则为之”但是对玩家社区造成了重大损失与伤害的事件，管理组会举行一次守则修改会议。修改后守则将视情况会对该事件生效。  
1.6 各位玩家如果需要按照守则解决冲突，请提供**强有力**的证据，如 logs、replay 等，帮助管理员做出正确的判定。

## 2. 游戏基本行为守则 🎮
### 2.1 通用守则 🔧
2.1.1 严禁在任何平台辱骂、诋毁、骚扰、言语攻击、甚至“开盒”、线下骚扰其他玩家和玩家群体。  
2.1.2 严禁在任何平台刷屏、发送大量无意义内容对其他玩家造成不良影响。  
2.1.3 一切如命名、地图画、描述等自定义创作内容，严禁出现带有侮辱性、攻击性、政治性、宗教性等一切不适于展示的符号与元素。  
2.1.4 严禁使用第三方软件进行如开挂、作弊、矿透等影响游戏公平的行为。  
2.1.5 严格禁止建造任何全自动农场、刷怪塔、刷铁机等违背“手动生产”原则的设施。如果一个设施能够全自动完成生产某个物品的所有步骤，或者玩家只需要使用挂机脚本进行简易操作就能完成生产，那么它就是全自动设施。  
2.1.6 禁止村民交易。

### 2.2 主世界 🌍
2.2.1 每一位玩家都**有义务自行保管**好个人财物和留存证据，对于在野外但却遭到损失的财物，如果无法提供指认违规者的证据，那么损失由个人承担。  
2.2.2 严禁破坏他人劳动成果，包括但不限于：玩家放置的方块（建筑、装饰、红石元件）、种植的作物（无论是否成熟）、驯服/命名的生物和坐骑、物品展示框内的物品、以及存储在容器（箱子、潜影盒等）内的任何物品等。  
2.2.3 严禁盗窃、掠夺他人财物，包括建筑、物品、装备、坐骑等一切被其他人所有的数据信息。  
2.2.4 严禁无理由对其他人进行任何形式骚扰或攻击，如果主张自己是正当防卫需提供充足证据。  
2.2.5 正当防卫应以降低自身损耗为目的，造成他人更大损失将被视为打击报复而不是正当防卫。  
2.2.6 严禁在他人领地周围32格内进行恶意破坏，如炸坑、修建无意义建筑、恶意破坏地形。  
2.2.7 严禁制作陷阱坑害、围堵其他玩家。  
2.2.8 严禁恶意圈地，如框选他人领地、独占重要的自然生成结构（试炼之地等）、领地长宽比大于4:1等。管理方将提前通知领主整改并有权强制删除领地。

### 2.3 下界 🔥
2.3.1 下界不对任何个人财物和人身安全提供保障，玩家进入下界视为已完全知晓此规则并同意由此可能对自身造成的损失。  
2.3.2 服务器不允许在下界创建面积大于16\*16或任一边长度大于32的领地，如果被发现，将提前通知领主整改并有权强制删除领地，造成的损失由领主自负。  
2.3.3 严禁在下界战斗时追杀已逃回主世界的玩家。

## 3. 核心经济规则 💰
3.1 服务器不提倡进行市场操作行为。如倾销、压价、恶意收购等。管理方在发现这种行为后会主动干预市场，如果因为服务器主动干预而遭受损失需自行承担。  
3.2 玩家间的所有交易、合作、竞争行为均属游戏内容，由此产生的正常游戏风险（如市场波动、合同违约、投资失败）需自行承担。  
3.3 如果出现合同违约、欠债不还等情况，需按照条约中明确表述的条款进行处理，按照其他方式处理不被管理方承认有效。玩家有义务明确合同条款。  
3.4 管理方有权强制执行经过审批的合同条款。

## 4. 社交与冲突解决 🤝
4.1 鼓励玩家通过游戏内机制（如合同条款、仲裁服务）自行解决纠纷。管理员不介入普通交易风险或合同条款争议。  
4.2 举报违规行为必须提供确凿证据（如截图、录像、具体时间地点）。诬告将受处罚。

## 5. 违规行为与处理措施 ⚖️
5.1 处罚阶梯：根据违规情节，处罚可分为：  
    - 警告  
    - 禁言  
    - 整改  
    - 强制整改  
    - 罚款  
    - 临时封禁  
    - 永久封禁  
5.2 对于利用 BUG 或作弊获得的资产，管理员有权进行追溯、没收或清零。

## 6. 免责声明 ⚠️
6.1 服务器将定期备份数据，但对于因不可抗力（如网络攻击、硬件故障）导致的数据损失，责任上限为尽可能恢复。  
6.2 服务器管理团队保留对守则的最终解释权及根据实际情况更新规则的权利。

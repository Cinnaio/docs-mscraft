# 客官守则

## 概述与修改权
:::tip 须知
本守则适用于所有在本服务器进行游戏的客官们，管理组将负责维护与编纂，所有客官们共有权力修改本守则。
:::
:::danger 严重
客官们在举报和申诉时请准备好足够、真实、充分、时效的证据。诬告者反坐其罪且罪加一等。
:::

如果出现 “法未禁止则为之” 但是对社区造成了重大损失与伤害的事件，管理组会举行一次守则修改会议，由客官代表提出修改意见，所有客官们进行投票以完成守则修改。修改后守则将会对该事件生效。

## 处罚机制及力度

处罚力度将按照违规指数进行量化，玩家每违规一次，都会按照条目前的处罚系数进行计算违规指数，按照玩家计算后的违规指数进行处罚。**如果屡犯，受到的处罚将会加重。**

|    处罚系数    	|              处罚措施             	|
|:--------------:	|:---------------------------------:	|
|       1~5      	|         禁言、警告、封禁0~12h     	|
|       6~10     	|                封禁12h            	|
|      11~20     	|               封禁3天             	|
|      21~50     	|          封禁14天+全服通报        	|
|      51~75     	|          封禁30天+全服通报        	|
|      75及以上    	|          永久封禁+全服通报        	|
|     100及以上    	|     永久封禁+全服通报+保留证据    	|

每一个玩家违规指数会累加，不过违规指数也可以通过其他方式进行恢复。

|       系数      	|              恢复方式             	|
|:---------------:	|:---------------------------------:	|
|        -2       	|            每月自然恢复           	|
|     撤回处罚    	|     出现误判、误会、污蔑等情况    	|
|        -3       	|     每个月积极参加社区建设活动    	|

以上处罚方式有选择时，视具体违反行为而定。比如辱骂等更多选择禁言，建造大型红石机械等更多选择封禁。
全服通报形式：在kook、qq群和服务器内主城定期发布处罚结果。

# msc群隙服务器客官守则

## 1. 总则 📜

- **1.1 严禁**玩家进行任何违反中华人民共和国法律的行为，服务器将保存一切证据，违者后果自负。
- **1.2 服务器核心理念**：本服为“玩家驱动的分流型经济社会模拟器”，核心玩法基于**手动生产、地理物流、市场交易与契约精神**。
- **1.3 守则目的**：为维护公平、可持续的游戏环境，保护玩家时间投入与资产安全，特制定本守则。所有玩家均视为已阅读并同意遵守。
- **1.4 规则适用范围**：适用于游戏内、官方社群、交易平台等一切与服务器相关的行为。
- **1.5 规则漏洞的处理**：如果出现“法未禁止则为之”但对玩家社区造成了重大损失与伤害的事件，管理组将举行守则修改会议。修改后的守则将视情况对该事件生效。
- **1.6 证据要求**：玩家如需依据守则解决冲突，必须提供**强有力的证据**（如 logs、replay 等），以协助管理员做出正确判定。

## 2. 游戏基本行为守则 🎮

### 2.1 通用守则 🔧

- **2.1.1 严禁**在任何平台辱骂、挑衅、诋毁、骚扰、言语攻击，甚至“开盒”、线下骚扰其他玩家或玩家群体。
- **2.1.2 严禁**在任何平台刷屏、发送大量无意义内容，对其他玩家造成不良影响。
- **2.1.3 自定义内容规范**：一切自定义创作（如命名、地图画、描述等）严禁包含侮辱性、攻击性、政治性、宗教性等任何不适于展示的符号与元素。
- **2.1.4 严禁**使用第三方软件进行开挂、作弊、矿透等影响游戏公平的行为。凡是不包含于群隙客户端的 mod、第三方软件或其他功能均不受支持。
- **2.1.5 严格禁止**建造任何全自动农场、刷怪塔、刷铁机等违背“手动生产”原则的设施。如果一个设施能够全自动完成某物品的所有生产步骤，或玩家仅需使用挂机脚本进行简易操作即可完成生产，则该设施属于**全自动设施（禁止）**。
- **2.1.6 禁止村民交易**。

### 2.2 主世界 🌍

- **2.2.1 自保义务**：每位玩家**有义务自行保管**个人财物并留存证据。对于野外丢失的财物，若无法提供指认违规者的证据，损失由个人承担。
- **2.2.2 严禁破坏他人劳动成果**，包括但不限于：玩家放置的方块（建筑、装饰、红石元件）、种植的作物（无论是否成熟）、驯服/命名的生物和坐骑、物品展示框内的物品、以及容器（箱子、潜影盒等）内存储的任何物品。
- **2.2.3 严禁盗窃、掠夺他人财物**，包括建筑、物品、装备、坐骑等一切归属于其他玩家的数据信息。
- **2.2.4 严禁无理由骚扰或攻击**其他玩家。若主张**正当防卫**，须提供充足证据。
- **2.2.5 正当防卫界限**：正当防卫应以降低自身损耗为目的，造成他人更大损失将被视为打击报复而非正当防卫。
- **2.2.6 严禁**在他人领地周围 32 格内进行恶意破坏（如炸坑、修建无意义建筑、恶意破坏地形）。
- **2.2.7 严禁**制作陷阱坑害、围堵其他玩家。
- **2.2.8 禁止**对主世界野外的公共设施进行大规模恶意破坏、占为己有等恶意行为。
- **2.2.9 严禁恶意圈地**，如框选他人领地、独占重要自然生成结构（试炼之地等）、领地长宽比大于 4:1。管理方将提前通知领主整改，并有权强制删除领地。

### 2.3 下界 🔥

- **2.3.1 风险自负**：下界不对任何个人财物和人身安全提供保障。玩家进入下界即视为完全知晓并同意承担由此可能造成的损失。
- **2.3.2 领地限制**：服务器不允许在下界创建面积大于 16×16 或任一边长度大于 32 的领地。若发现，将提前通知领主整改，并有权强制删除领地，损失由领主自负。
- **2.3.3 严禁**在下界战斗时追杀已逃回主世界的玩家。
- **2.3.4 墓碑失去保护**：在下界，玩家可开启任何人的墓碑（无论是否处于保护状态），请对自身安全负责。

## 3. 自动化设施定义与限制 🤖

- **3.1 根本目的**：禁止自动化设施的目的是防止玩家以无成本或极低成本批量生产资源，维护手动生产的核心理念。
- **3.2 自动化定义**：凡完全不需要玩家参与即可完成生产，或玩家仅需使用挂机脚本等简易操作即可完成生产的行为，均视为自动化生产，予以禁止。

### 3.3 农业规定 🌾

- **3.3.1** 对于收获后需要补种的作物（如小麦、土豆等），允许自动化收获和收集掉落物，例如使用水流冲走农作物后以漏斗收集。
- **3.3.2** 对于收获后不需要补种的作物（如西瓜、甘蔗等），不允许自动化收获和收集掉落物，例如观察者+活塞自动收获甘蔗。
- **3.3.3 例外**：允许使用狐狸自动化收获甜浆果，以及使用漏斗矿车等功能进行收集。

### 3.4 畜牧业规定 🐄

- **3.4.1** 对于一般食物类产出（如鸡肉、牛肉等），允许建造设施对动物进行成年与幼年分离并自动处死，例如烤鸡机和烤牛机。
- **3.4.2** 对于鸡蛋，**严禁使用漏斗**等任何方式全自动收集鸡蛋。
- **3.4.3** 对于羊毛产出，禁止使用任何全自动设施自动剪羊毛。
- **3.4.4** 对于蜜蜂相关产出，允许使用营火烟熏蜂巢或蜂箱，但玩家必须手动收集产物。

### 3.5 渔业规定 🎣

- **3.5.1** 允许玩家使用自动钓鱼mod一人一杆自动钓鱼，并允许在钓鱼位置修建自动收集鱼获的设施（例如在玩家面前放置漏斗收集掉落的鱼）。
- **3.5.2** 禁止将自然生成的鱼类通过任何方式自动化伤残、处死并收集，例如建造大型鱼塔。

### 3.6 林业与矿业规定 🌲

- **3.6.1** 禁止利用 TNT 复制等漏洞无成本破坏方块，例如用于树场或刷石机等。
- **3.6.2** 允许玩家挂机采集水与岩浆接触生成的圆石/石头并自动收集。

### 3.7 刷怪规定 👾

- **3.7.1 地牢刷怪笼、烈焰人刷怪笼、废弃矿井刷怪笼**：允许玩家利用水流等将生成的怪物聚集并困住，使其无法伤害玩家，但**禁止**通过摔伤、燃烧等方式自动将怪物伤害至低血量。怪物必须由玩家从满血或几乎满血状态攻击致死。允许使用漏斗自动收集掉落物。
- **3.7.2 试炼密室、劫掠**：不允许玩家改造地形或建造设施使生成的怪物**难以移动、被困住、被伤害或被处死**。必须进行正常 PVE 游戏，即怪物能够**正常攻击并伤害到玩家**。允许将地形改造得平坦、宽阔以更适合 PVE，但不得建造使玩家完全免疫伤害的掩体或封闭空间。
- **3.7.3 刷怪塔、女巫塔等**：限制方式与试炼密室类似，允许建造平坦、宽阔地形方便怪物生成，但禁止通过机关、设施（如水流）等让怪物难以行动或非玩家原因聚怪。可以修建墙体等保护措施让怪物无法伤害玩家，但不得利用这些措施使怪物无法移动或聚集。允许建造特种刷怪场所（如专刷苦力怕的场所），并允许使用漏斗自动收集掉落物。

### 3.8 非生产类自动化设施规定 🏭

- **3.8.1 高速熔炉组**：允许建造，但燃料必须具有成本，严禁使用刷地毯机等任何自动化方式无限供应燃料。
- **3.8.2 全自动炼药机**：允许建造。
- **3.8.3 自动合成设施**：允许使用合成器搭建自动化合成设施。
- **3.8.4 物品分类机**：允许建造。
- **3.8.5 物流运输系统**：允许利用铁路系统和箱子矿车建造自动化物流运输系统。
- **3.8.6 红石陷阱**：允许在合理区域（如下界）建造可触发的红石陷阱，例如 TNT 地雷。
- **3.8.7 攻击性红石设施**：允许在合理区域建造攻击性红石设施，例如 TNT 炮。
- **3.8.8 高级红石电路与逻辑计算机**：禁止建造，因其过度消耗服务器性能。
- **3.8.9 长期运行的红石高频**：禁止任何长期运行的红石高频电路，理由同上。
- **3.8.10 红石音乐类设施**：允许建造。
- 未列出的自动化设施默认是不允许的，如果你觉得你将要建造的非生产类自动化设施不属于上述类别但不会对服务器性能造成大的影响，可以反馈给管理员调整规则。
## 4. 核心经济规则 💰

- **4.1 市场操作行为**：服务器不提倡进行市场操作行为（如倾销、压价、恶意收购等）。管理方发现后将主动干预市场，因干预造成的损失由玩家自行承担。
- **4.2 交易风险自理**：玩家间的所有交易、合作、竞争行为均属游戏内容，由此产生的正常游戏风险（如市场波动、合同违约、投资失败）需自行承担。
- **4.3 合同优先**：若出现合同违约、欠债不还等情况，须按照条约中明确表述的条款处理，其他处理方式管理方不予承认。玩家有义务明确合同条款。
- **4.4 合同执行权**：管理方有权强制执行**经过审批**的合同条款。

## 5. 社交与冲突解决 🤝

- **5.1 鼓励自助解决**：鼓励玩家通过游戏内机制（如合同条款、仲裁服务）自行解决纠纷。管理员不介入普通交易风险或合同条款争议。
- **5.2 举报要求**：举报违规行为必须提供**确凿证据**（如截图、录像、具体时间地点），**诬告将受处罚**。
- **5.3 妨碍公务**：严禁玩家在服务器管理员执行公务（包括但不限于日常巡查、聊天内容管理、技术调试等）时进行任何形式的骚扰、妨碍或干扰。严禁无故多次骚扰管理员，以及实施虚假举报等恶意占用管理员人力资源行为。

## 6. 违规行为与处理措施 ⚖️

- **6.1 处罚阶梯**：根据违规情节，处罚可分为：
  - 警告
  - 禁言
  - 整改
  - 强制整改
  - 追缴违法所得
  - 罚款
  - 临时封禁
  - 永久封禁
- **6.2 违规收益处理**：对于利用 BUG 或作弊获得的资产，管理员有权进行追溯、没收或清零。

## 7. 免责声明 ⚠️

- **7.1 数据备份与责任**：服务器将定期备份数据，但对于因不可抗力（如网络攻击、硬件故障）导致的数据损失，责任上限为尽可能恢复。
- **7.2 守则解释权**：服务器管理团队保留对守则的最终解释权及根据实际情况更新规则的权利。

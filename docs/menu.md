# 新人指南

欢迎来到服务器！这里为你准备了从入门到进阶的新人指南，包含生存基础、坐骑出行、经济交易与成就系统等内容。阅读本页后，你可以继续查看细分教程：

- 经济交易：EchoMarket 全球市场与 PrismMarket 动态市场
- 出行坐骑：Transportation 坐骑契约与召回
- 成就进度：Milestone 里程碑与奖励

---

## 入门基础
- 第一天生存：采集木头→合成工作台→木镐→石质工具→临时庇护所与火把。
- 食物获取：最稳妥的是种植小麦做面包；也可以狩猎或钓鱼。
- 工具升级：石→铁→钻石；尽早获得盾牌与铁甲以提升生存率。
- 资源开采：在 Y≈-59 附近挖矿以提高钻石效率；注意带足木材与食物。

:::tip
夜间尽量避免在野外停留，优先确保光照与安全空间。
:::

## 出行坐骑（Transportation）
- 核心概念：契约、兽栏、信物。坐骑属性与状态会被完整保存。
- 快速上手：
  - 驯服生物后执行 `/tra bind` 
  - 制作信物：手持物品执行 `/tra keybind <代号>`
  - 召唤/收回：手持信物右键；或使用 `/tra out <代号>` 与 `/tra in <代号>`
- 查看坐骑列表：`/tra list`
- 详细教程：[Transportation](./tutorial/Transportation.md)

## 经济与交易
### EchoMarket 全球市场
- 开店：面对空地输入 `/market create <商店名称>`，生成你的 NPC 店员。
- 上架：手持物品执行 `/market sell <价格>`；支持改名与简介。
- 浏览：`/market` 打开全服市场；实体购买需在 NPC 附近。
- 详细教程：[EchoMarket](./tutorial/EchoMarket.md)

### PrismMarket 动态市场
- 进入：`/pm` 或 `/prismmarket` 打开市场；`/pm weekly` 直达每周系统回收商店。
- 交易：GUI 左键购买、右键出售（以物品描述为准）。
- 刷新：每日/每周/活动随机轮换；部分商品设有个人/全服限额。
- 详细教程：[PrismMarket](./tutorial/PrismMarket.md)

## 成就与奖励（Milestone）

- 排行统计：服务器会定期刷新排行榜，展示活跃与进度较快的玩家。
- 详细教程：[Milestone](./tutorial/Milestone.md)

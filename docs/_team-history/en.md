## History {#history-heading}

Brief milestones below. Later contributors are welcome to expand this based on the facts.

- **2022** — The project was launched; limited time and people meant it could not be carried forward and was set aside for a time.
- **2024** — The project restarted, with **social simulation** as the focus and a new initiative: **ClusterGap** (群隙 / cgap).
- **2024.12 – 2025.6** — **Season 1**: a small-scale run aimed mainly at validating the economic model and core gameplay.

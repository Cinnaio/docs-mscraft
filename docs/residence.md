# Residence 领地系统基础指南

> **核心摘要**：Residence 用于“圈地保护 + 权限管理”。本服开启租期与经济费用，并要求领地之间至少 **32 格**间距；同时 **禁用所有 Residence 传送功能**。

## 核心概念

- **领地（Residence）**：用木锄选择区域后创建的保护范围。领地内的放置/破坏/交互等行为都可按权限控制。
- **权限（Permissions）**：控制玩家在领地内能做什么（例如 build/use/container/pvp）。
- **子领地（Subzone）**：在领地内部再划分小区域，单独设置权限，适合多人合住或公共区/私人区分离。

## 创建领地

### 准备工作

- **工具**：木锄（可用 `/res tool` 直接获取选区工具）。
- **费用**：新建/扩展领地按 **15.625 金币/方块** 计费。
- **间距规则**：不同玩家领地之间必须至少 **32 格**距离，避免冲突。

### 圈地与创建

1. 用木锄选择两个对角点：
   - **左键**：第一个点（绿色粒子）
   - **右键**：第二个点（红色粒子）
2. 创建领地：

```
/res create <领地名称>
```

示例：

```
/res create myhome
```

> 提示：创建成功后会自动扣费，并为领地赋予 **7 天租期**（到期需续租）。

### 查看信息

- **当前所在领地**：`/res info`
- **我的全部领地**：`/res list`

## 权限管理

领地默认只有领主可建造。建议只给信任玩家开放权限，不要直接对所有访客开放 build。

### 常用：添加/移除成员

- **添加成员（简写）**：`/res padd <玩家名>`（常用于允许建造）
- **移除成员**：`/res pdel <玩家名>`

### 设置权限

全局默认权限（对“访客/所有人”）：

```
/res set <权限名> <true|false|remove>
```

对单个玩家单独设置：

```
/res pset <玩家名> <权限名> <true|false>
```

常用权限示例：

- **build**：放置/破坏方块
- **use**：使用门、工作台、铁砧等
- **container**：打开箱子、熔炉等容器
- **pvp**：领地内 PVP
- **tp**：传送相关（本服禁用 Residence 传送，**此权限无效**）

## 子领地（Subzone）

当你需要“公共区/私人房间”分隔时，推荐使用子领地。

1. 站在父领地内，用木锄选择子区域。
2. 创建子领地：

```
/res subzone <子领地名称>
```

子领地权限会覆盖父领地，可在子领地范围内直接使用 `/res set` / `/res pset` 单独配置。

## 传送与删除

> 重要：本服务器已禁用 Residence 插件的所有传送功能（如 `/res go` 等）。返回领地请自行步行或使用其他交通方式。

### 删除领地（不可逆）

1. 在领地内执行：`/res remove`
2. 按提示确认：`/res confirm`
3. **返还**：删除领地后按 **5.625 金币/方块** 返还部分资金。

## 经济与租期

本服开启租期系统：领地创建时默认 **7 天租期**；到期未续租会被自动删除（物品会掉落）。

### 费用一览

| 项目 | 价格（每方块） |
| :--- | :--- |
| 新建/扩展领地 | **15.625 金币** |
| 删除领地返还 | **5.625 金币** |
| 续租（7天） | **2.856 金币** |

### 续租

```
/res renew <领地名称>
```

执行一次会续租 **7 天**，费用 = 领地总方块数 × 2.856。可随时用 `/res info` 查看剩余租期。

## 常见问题（FAQ）

:::: details Q: 如何扩大或缩小领地？
A:

- 扩大：`/res expand <格数>`（向面朝方向扩展）
- 缩小：`/res contract <格数>`

扩展会按新增方块数扣费。
::::

:::: details Q: 领地之间需要保持多少距离？
A: 至少 **32 格**。建议在创建前用选区预览范围，避免冲突。
::::

:::: details Q: 领地传送可以用吗？
A: 不可以。本服已禁用 Residence 插件所有传送相关功能（包括 `/res go` 等）。
::::

:::: details Q: 如何转让领地给其他玩家？
A:

```
/res give <领地名称> <玩家名>
```
::::

:::: details Q: 权限乱了怎么重置？
A: `/res default` 可恢复默认权限设置。
::::

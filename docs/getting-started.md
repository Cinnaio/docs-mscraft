# 欢迎来到群隙 ClusterGap

欢迎加入我们的世界！在这里，你将体验到一个独特且充满活力的社区。无论你是建筑师、探险家还是红石工程师，这里都有属于你的一片天地。

## 玩家守则

为了维护良好的游戏环境，请各位玩家遵守以下基本规则：

1. **友善交流**：禁止辱骂、骚扰或歧视其他玩家。
2. **公平游戏**：严禁使用任何形式的作弊客户端或破坏游戏平衡的模组。
3. **尊重劳动**：未经允许，请勿破坏他人的建筑或窃取物品。
4. **爱护环境**：请勿进行无意义的地形破坏或高频红石卡服行为。

*更加详细的玩家守则，请参考[玩家守则](server-faq.md)。*

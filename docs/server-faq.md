# 服务器规则

## 总则

> **核心摘要**：本章规定了服务器的法律底线与核心运营理念，强调**手动生产**与**契约精神**，旨在维护公平、可持续的游戏环境。

- **法律底线**：严禁玩家进行任何违反中华人民共和国法律的行为，服务器将保存一切证据，违者后果自负。
- **核心理念**：本服为“玩家驱动的分流型经济社会模拟器”，核心玩法基于**手动生产、地理物流、市场交易与契约精神**。
- **守则目的**：为维护公平、可持续的游戏环境，保护玩家时间投入与资产安全，特制定本守则。所有玩家均视为已阅读并同意遵守。
- **适用范围**：适用于游戏内、官方社群、交易平台等一切与服务器相关的行为。
- **漏洞处理**：如果出现“法未禁止则为之”但对玩家社区造成了重大损失与伤害的事件，管理组将举行守则修改会议。修改后的守则将视情况对该事件生效。
- **证据要求**：玩家如需依据守则解决冲突，必须提供**强有力的证据**（如 logs、replay 等），以协助管理员做出正确判定。

## 游戏基本行为守则

> **核心摘要**：严禁作弊、破坏与恶意骚扰。主世界需遵守财物自保与领地规则，下界为高风险区域，后果自负。

### 通用守则

- **言行规范**：严禁在任何平台辱骂、挑衅、诋毁、骚扰、言语攻击，甚至“开盒”、线下骚扰其他玩家或玩家群体。
- **拒绝刷屏**：严禁在任何平台刷屏、发送大量无意义内容，对其他玩家造成不良影响。
- **内容规范**：一切自定义创作（如命名、地图画、描述等）严禁包含侮辱性、攻击性、政治性、宗教性等任何不适于展示的符号与元素。
- **严禁作弊**：严禁使用第三方软件进行开挂、作弊、矿透等影响游戏公平的行为。凡是不包含于群隙客户端的 mod、第三方软件或其他功能均不受支持。
- **拒绝全自动**：严格禁止建造任何全自动农场、刷怪塔、刷铁机等违背“手动生产”原则的设施。如果一个设施能够全自动完成某物品的所有生产步骤，或玩家仅需使用挂机脚本进行简易操作即可完成生产，则该设施属于**全自动设施（禁止）**。
- **交易限制**：禁止村民交易。

### 主世界

- **自保义务**：每位玩家**有义务自行保管**个人财物并留存证据。对于野外丢失的财物，若无法提供指认违规者的证据，损失由个人承担。
- **保护劳动成果**：严禁破坏他人劳动成果，包括但不限于：玩家放置的方块、种植的作物、驯服/命名的生物和坐骑、物品展示框内的物品、以及容器内存储的任何物品。
- **严禁盗窃**：严禁盗窃、掠夺他人财物，包括建筑、物品、装备、坐骑等一切归属于其他玩家的数据信息。
- **禁止骚扰**：严禁无理由骚扰或攻击其他玩家。若主张**正当防卫**，须提供充足证据。
- **正当防卫**：正当防卫应以降低自身损耗为目的，造成他人更大损失将被视为打击报复而非正当防卫。
- **领地保护**：严禁在他人领地周围 32 格内进行恶意破坏（如炸坑、修建无意义建筑、恶意破坏地形）。
- **禁止陷阱**：严禁制作陷阱坑害、围堵其他玩家。
- **公共设施**：禁止对主世界野外的公共设施进行大规模恶意破坏、占为己有等恶意行为。
- **圈地规范**：严禁恶意圈地，如框选他人领地、独占重要自然生成结构（试炼之地等）、领地长宽比大于 4:1。管理方将提前通知领主整改，并有权强制删除领地。

### 下界

- **风险自负**：下界不对任何个人财物和人身安全提供保障。玩家进入下界即视为完全知晓并同意承担由此可能造成的损失。
- **领地限制**：服务器不允许在下界创建面积大于 16×16 或任一边长度大于 32 的领地。若发现，将提前通知领主整改，并有权强制删除领地，损失由领主自负。
- **跨界追杀**：严禁在下界战斗时追杀已逃回主世界的玩家。
- **墓碑无保护**：在下界，玩家可开启任何人的墓碑（无论是否处于保护状态），请对自身安全负责。

## 自动化设施定义与限制

> **核心摘要**：维护手动生产价值，禁止无成本/低成本的完全自动化量产。允许部分半自动化与辅助设施。

- **根本目的**：防止玩家以无成本或极低成本批量生产资源，维护手动生产的核心理念。
- **自动化定义**：凡完全不需要玩家参与即可完成生产，或玩家仅需使用挂机脚本等简易操作即可完成生产的行为，均视为自动化生产，予以禁止。

### 农业规定

- **需补种作物**：允许自动化收获和收集掉落物（如小麦、土豆），例如使用水流冲走后以漏斗收集。
- **无需补种作物**：不允许自动化收获和收集掉落物（如西瓜、甘蔗），例如观察者+活塞自动收获甘蔗。
- **例外情况**：允许使用狐狸自动化收获甜浆果，以及使用漏斗矿车等功能进行收集。

### 畜牧业规定

- **食物产出**：允许建造设施对动物进行成年与幼年分离并自动处死（如烤鸡机、烤牛机）。
- **鸡蛋收集**：**严禁使用漏斗**等任何方式全自动收集鸡蛋。
- **羊毛产出**：禁止使用任何全自动设施自动剪羊毛。
- **蜜蜂产出**：允许使用营火烟熏蜂巢或蜂箱，但玩家必须手动收集产物。

### 渔业规定

- **自动钓鱼**：允许玩家使用自动钓鱼 mod 一人一杆自动钓鱼，并允许修建自动收集设施。
- **鱼塔限制**：禁止将自然生成的鱼类通过任何方式自动化伤残、处死并收集。

### 林业与矿业规定

- **禁止刷物**：禁止利用 TNT 复制等漏洞无成本破坏方块（如树场、刷石机）。
- **刷石机**：允许玩家挂机采集水与岩浆接触生成的圆石/石头并自动收集。

### 刷怪规定

- **常规刷怪笼**：允许聚怪困怪，但**禁止**自动修血。怪物必须由玩家从健康状态攻击致死。允许自动收集掉落物。
- **试炼/劫掠**：禁止改造地形使怪物被困或无法攻击。必须进行正常 PVE，允许平整场地但禁止无敌掩体。
- **刷怪塔/女巫塔**：禁止通过机关/水流限制怪物行动或聚怪。允许平整场地方便生成，允许修建保护墙体。允许特种刷怪场所（如苦力怕场）并自动收集。

### 非生产类自动化设施规定

- **高速熔炉**：允许建造，燃料须有成本，严禁无限燃料。
- **炼药/合成**：允许全自动炼药机与自动合成设施。
- **物流/分类**：允许物品分类机与矿车物流系统。
- **攻击性设施**：允许在合理区域（如下界）建造红石陷阱与 TNT 炮。
- **性能限制**：禁止高级红石电路、逻辑计算机及长期运行的高频电路。
- **其他**：允许红石音乐设施。未列出设施默认禁止，如有需求请联系管理。

## 核心经济规则

> **核心摘要**：市场自由，风险自担。管理组仅在恶意操纵市场或重大违约时介入。

- **市场干预**：不提倡倾销、压价、恶意收购等操作。管理方发现后将主动干预，损失由玩家承担。
- **风险自理**：交易、合作、竞争风险（如市场波动、违约）由玩家自行承担。
- **契约精神**：合同违约按条款处理，玩家有义务明确条款。
- **强制执行**：管理方有权强制执行**经过审批**的合同条款。

## 社交与冲突解决

> **核心摘要**：提倡沟通与自治，举报违规必须提供确凿证据。

- **自助解决**：鼓励通过游戏机制（合同、仲裁）解决纠纷。管理员不介入普通争议。
- **举报证据**：举报必须提供**确凿证据**（截图、录像），**诬告将受处罚**。
- **配合管理**：严禁骚扰、妨碍管理员执行公务，严禁虚假举报。

## 违规行为与处理措施

> **核心摘要**：违规必究，从警告到封禁，非法所得一律追缴。

- **处罚阶梯**：警告 → 禁言 → 整改 → 强制整改 → 追缴 → 罚款 → 临时封禁 → 永久封禁。
- **追溯处理**：利用 BUG 或作弊获得的资产，管理员有权追溯、没收或清零。

## 免责声明

> **核心摘要**：数据尽力保护，最终解释权归管理团队所有。

- **数据责任**：定期备份数据，因不可抗力导致的数据损失，责任上限为尽可能恢复。
- **解释权**：服务器管理团队保留对守则的最终解释权及更新权利。


## 服务器FAQ

::: details Q: 服务器如何注册？
A: 有两种方式注册服务器：
1. **正版账号**：直接使用正版账号进入服务器，无需任何注册。
2. **外置登录**：在服务器指定的[皮肤站](https://skin.cubem.cn/)进行注册，然后使用外置登录进入服务器。

# 六种干叶

## 绿茶干叶

干燥的绿茶叶，可用于泡制绿茶。

### 获取方式

|   材料   	|                 合成方式                	|     备注     	|
|:--------:	|:---------------------------------------:	|:------------:	|
| [绿茶鲜叶](./tea_leaf.md)*1 	|   无   	| **发酵桶** 使用<p />绿茶鲜叶的基础上发酵 <p />5min / 15xp 	|

## 白茶干叶

|   材料   	|                 合成方式                	|     备注     	|

| [绿茶青叶](./half_dried_tea.md)*1 	|   ![合成](../../image/recipes/teastory/others/white_tea_leaf.png)  	| **烟熏炉** 使用<p />绿茶青叶的基础进行烟熏 <p />6min 36xp 	|
